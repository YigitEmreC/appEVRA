# Changelog

## 0.1.0

- First version: serves the Evra app on port 8099 and in Home Assistant's sidebar.
- Phones and wall panels connect to this Home Assistant without setup.
- Open screens reload by themselves after an update, when nobody is using them.
- Security headers, including a Content Security Policy that only lets Evra's own scripts run.
- Phones re-register for notifications each time Evra opens, so alerts keep arriving.
